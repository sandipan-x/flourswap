# FlourSwap

Flour substitution chart & converter: swap AP, bread, cake, whole wheat, rye and oat flours by exact weight. Cup-gram tables and protein notes included.

## Features
- Cup-to-gram reference table for 6 flours
- Protein percentage notes for every flour
- One-tap swap presets for popular bakes
